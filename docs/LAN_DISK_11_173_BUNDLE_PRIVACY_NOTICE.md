## 4. 1.7.4 的脱敏来源与检查范围

**来源**：1.7.4 的桌面矩阵在工作台运行时即使用 **WLAN 夹具**，不再读取本机真实无线状态 ——
由两条可执行断言保证（`UI_CAPTURE_ENVIRONMENT.tsv`）：

- `WLAN12-01_NATIVE_WLAN_CALLS` = 0：矩阵期间一次都没有调用真实 WLAN 服务；
- `WLAN12-02_FIXTURE_SENTINEL_SEEN` = PASS：夹具的哨兵网络确实出现在 WiFi 页上。

因此 1.7.4 的 WiFi 页截图从一开始就不含真实 SSID。

**检查范围**（素材产生后逐项执行）：

| 对象 | 检查内容 |
| --- | --- |
| 截图 | WiFi 页及其它页面是否出现真实 SSID / 适配器型号 |
| 录屏与动图 | 逐帧同上；安装器录屏另确认不出现网络标识 |
| 日志 | 服务器与更新程序日志中的地址、适配器、SSID |
| 诊断文本 | `UI_LAYOUT_VERIFICATION.tsv`、`UI_INJECTION_PROBE.tsv`、注入探针的转义文本与 Unicode 码点 |

被测产物哈希）。这些是候选核验的依据，脱敏只针对真实网络标识。
