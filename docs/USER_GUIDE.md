# LanDisk 中文使用说明

适用版本：1.1.0（`LAN_DISK_DSH_UX_AUTH_UPGRADE_02` 交付版本）
适用平台：Windows 10 / 11（64 位）；iPhone Safari 或同一局域网内的其他浏览器。

---

## 1. 安装与启动

1. 把 `LanDisk-win-x64.zip` 解压到任意目录，例如 `D:\LanDisk`。
   解压后会得到一个 `LanDisk-win-x64` 文件夹（里面就是程序本体）。
   运行包是**自包含**的，已经带有 .NET 运行时，不需要另外安装任何东西。
2. 双击该文件夹里的 `LanDisk.Server.exe` 启动。会弹出控制台窗口，显示：

   ```
   LanDisk 已启动。
     数据目录: C:\Users\<你>\AppData\Local\LanDisk
     监听地址: http://127.0.0.1:8891, http://[::1]:8891, https://127.0.0.1:8892
     本机管理: http://127.0.0.1:8891/admin#token=<一次性管理令牌>
     共享数量: 0，设备数量: 0
     局域网: 未开启（仅本机可访问）。在管理页面中显式开启后重启生效。
   ```

3. **用这台电脑的浏览器打开** `http://127.0.0.1:8891/admin`。

   **不需要复制或粘贴任何令牌。** 真正来自本机回环地址、且是同源页面的请求会自动进入管理端。
   控制台里那行带 `#token=` 的网址只是**恢复方式**（例如浏览器禁用了 Cookie 时），
   平时用不到。

> 第一次启动时不会共享任何目录，也不会监听局域网，更不会修改防火墙、证书信任或开机启动项。
> 你可以在完全不影响系统的情况下先熟悉界面。

### 正常退出

管理页面右上角有「退出 LanDisk」按钮。也可以直接在控制台窗口按 `Ctrl+C`，或关闭控制台窗口。

退出时：
- 所有正在进行、尚未提交的上传会被取消，暂存文件会被清理；
- 已经提交到共享目录的文件不受影响；
- 回收站内容保留；
- 已配对设备的状态保留在数据目录中，下次启动后仍然有效。

## 2. 共享授权（电脑端）

进入管理页「共享」标签 → 点「添加共享」：

1. 在目录选择器里逐级进入，选中要开放的**文件夹**或**整个移动硬盘盘符**。
   选择器只会列出目录名，不会读取或显示文件内容。
2. 可选：填写一个共享名称（默认用文件夹名）。
3. 勾选该共享允许的能力：**允许上传**、**允许重命名**、**允许删除**（查看/下载始终允许）。
4. 点「共享此目录」。

注意事项：

- LanDisk **绝不会自动共享任何磁盘**，包括系统盘。每一次都必须由你在这里明确选择。
- 不能共享 LanDisk 自己的内部目录（数据目录、暂存区、回收站），也不能共享程序安装目录。
- 共享根目录本身不能是符号链接、junction 或挂载点（会被拒绝并说明原因）。
- 系统盘根目录虽然技术上可以选，但强烈不建议；请选择具体的子目录。

### 单独关闭 / 修改

- 每行的「启用」勾选框可以临时关闭某个共享，手机端会立刻收到「该共享已被本机关闭」。
- 三个权限勾选框可以随时调整，保存后立即对手机生效。
- 「重新确认磁盘」用于移动硬盘换过盘符、或你确认过磁盘内容之后的重新绑定。
- 「删除」只停止对外提供，**不会删除共享目录里的任何文件**。

## 3. 手机配对

1. 电脑端管理页「添加设备」→「生成配对请求」。
2. 页面会出现二维码、6 位配对码和一条配对链接，**2 分钟内有效且只能使用一次**。
3. 在 iPhone 上：

   **方式 A（推荐）**：用 iPhone 相机扫描二维码，或把配对链接发到手机上直接打开，
   页面会自动完成配对。

   **方式 B**：在 iPhone 上打开 `https://<电脑IP>:8892/pair`，在设备名称里填一个好认的名字
   （例如「我的 iPhone」），输入 6 位配对码并提交。
   然后回到**电脑端**「添加设备」列表，点该请求的「**确认配对**」。
   iPhone 页面会自动完成配对。

4. 配对成功后 iPhone 会进入文件列表页面。

**新配对的设备默认只有「查看和下载」权限。** 要给某台手机开启上传/重命名/删除：

- 在「设备」里把该设备的权限从「只读」改为「可读写」；
- 并且确认对应共享本身也勾选了相应能力；
- 两者取交集，缺一不可。

### 撤销设备 / 关闭共享

- 「设备」→「撤销」：该手机立即失效，需要重新配对。撤销会同时取消 LanDisk 仍在控制中的上传。
- 「共享」→ 取消「启用」：手机端立即无法访问该共享。

> **重要且无法回避的限制**：撤销只能停止 LanDisk 还在控制中的传输。
> 手机**已经下载或已经缓存**的文件、已经缓冲的播放内容，无法被远程收回。
> 这不是本版本的缺陷，而是「数据已经离开电脑」这一事实本身。

### 解除手机端配对

iPhone 页面「设备」标签 → 「解除本机配对」。
这只会清除这台手机上的登录状态；已下载到手机的文件不会删除，电脑端仍保留该设备记录，
可以再到电脑端彻底撤销。

## 4. 让 iPhone 连上电脑

### 4.1 打开局域网访问

管理页「网络」标签：

1. 勾选「**允许局域网设备访问**」。
2. 选择加密方式：
   - 勾选「**启用 HTTPS（推荐）**」，或
   - 勾选「**启用未加密的 HTTP 兼容模式（有风险）**」。
   两者至少要选一个，否则保存会被拒绝。
3. 可选：把「绑定网卡地址」限定到具体的网卡；「允许的来源网段」可进一步限制为例如 `192.168.1.0/24`。
4. 点任意一处保存后，页面会提示：**网络设置已保存，请退出并重新启动 LanDisk 使其生效**。
   端口和监听地址在启动时确定，这是有意为之——避免运行中意外地把服务暴露到新的网卡上。
5. 「退出 LanDisk」按钮退出，然后重新双击 `LanDisk.Server.exe`。

重启后管理页「状态」里能看到实际监听地址，例如 `https://192.168.1.23:8892`。

### 4.2 找到电脑的局域网地址

管理页「网络」标签下方列出本机所有私有 IPv4 地址（例如 `192.168.1.23`）。
手机端就用这个地址加端口访问：`https://192.168.1.23:8892/`。

> 电脑可以用网线，手机用 Wi-Fi，只要在同一个局域网并且路由器没有开启「AP 隔离 / 客户端隔离」即可。
> 「Wi-Fi 名字一样」并不保证互相可达。

### 4.3 Windows 防火墙

**LanDisk 不会自动修改防火墙。** 如果 iPhone 连不上而电脑上本机可以打开管理页：

1. 打开「Windows Defender 防火墙」→「允许应用或功能通过 Windows Defender 防火墙」。
2. 点「更改设置」→「允许其他应用」→ 选择 `LanDisk.Server.exe`。
3. **只勾选「专用」网络**，不要勾选「公用」。
4. 如果网络类型是「公用网络」，请先在「设置 → 网络和 Internet」中把它改成「专用网络」，
   或者手动添加一条仅限「专用」配置文件和本地子网的入站规则（TCP，端口 8891/8892）。

不要为了图省事关掉整个防火墙，也不要把端口映射到公网。

## 5. HTTPS 证书的安装与信任（iPhone）

LanDisk 会在本机生成一张**专用自签名证书**：私钥只保存在电脑上，不会下发给手机，
也不会自动安装到任何信任库。

1. iPhone 先用 **HTTP 兼容模式** 或按提示打开管理页下载证书（也可以把
   `数据目录\tls\landisk-root.cer` 传到手机上）。
   管理页「HTTPS」标签里有「下载证书文件（.cer）」按钮（仅本机可访问）。
2. iPhone：用 Safari 下载后，**设置 → 通用 → VPN 与设备管理 → 安装该描述文件**。
3. iPhone：**设置 → 通用 → 关于本机 → 证书信任设置 → 打开对该证书的完全信任**。

> **手动安装 ≠ 已经信任。** 不做第 3 步，Safari 会一直提示「此连接非私人连接」。
> 这不是可以点「继续访问」就忽略的问题——那等于放弃了 TLS 的保护。
> 安装前请核对管理页上显示的 SHA-256 指纹，确认来源正确。

**不再需要时如何撤销：**

- 设置 → 通用 → VPN 与设备管理 → 删除该描述文件；
- 设置 → 通用 → 关于本机 → 证书信任设置 → 关闭对应开关。

**证书过期或换了电脑/网卡地址后**：管理页「HTTPS」→「重新生成证书」，
然后在 iPhone 上删除旧描述文件并按上面步骤重新安装。证书的 SAN 会自动包含本机当前所有私有 IP 地址。

## 6. HTTP 兼容模式的真实风险

HTTP 兼容模式**默认关闭**，只有你明确勾选后才会启用，并且界面会一直显示未加密警告。

它的含义是：

- 同一局域网内的其他人**可能截获或篡改**传输中的配对令牌、文件名、文件内容；
- 手机浏览器不会把它当作安全上下文，因此不会有完整的安全上下文能力；
- **配对、CSRF 防护、权限校验都不能解决「传输未加密」这个问题**，它们解决的是另外的问题。

请只在**你完全信任的局域网**（例如家里自己的路由器）中临时使用，并尽快改用 HTTPS。
不要在公司、酒店、机场、公共 Wi-Fi 下使用 HTTP 兼容模式。

## 7. 手机端使用

在 iPhone Safari 中打开 `https://<电脑IP>:8892/`（HTTP 兼容模式则是 `http://<电脑IP>:8891/`）。

界面是手机优先的文件管理器，**打开后直接进入文件列表**，不会要求输入任何令牌。

### 布局

- **手机竖屏**：底部有 5 个入口 —— 文件 / 最近 / 收藏 / 回收站 / 我的；顶部是返回、当前目录名和搜索框。
- **手机横屏**：同样的界面，列表自动变宽。
- **桌面/平板宽屏**：左侧出现导航栏（文件、最近、收藏、回收站、传输、共享位置列表），
  并且文件列表会显示「名称 / 修改时间 / 类型 / 大小」四列，直接点表头即可排序。
  顶部和底部导航不会重复出现。

### 文件页

- **面包屑**在搜索框下方，点任意一级可以跳回去。
- 工具条：**排序**、**筛选**、**列表/网格**切换，以及「上传」和「新建文件夹」。
- 文件行显示图标或缩略图、名称、大小和修改时间。
- **点文件夹**进入；**点文件**打开预览/播放。
- **长按**任意文件或文件夹进入多选（电脑上是右键）。
- 每行右侧的 `…` 打开该文件的更多操作：预览、下载、收藏、重命名、选择、删除。

### 排序

点工具条上的排序按钮（显示当前排序方式），可选：

| 选项 | 说明 |
|---|---|
| 名称 A → Z / Z → A | 自然排序：`file2` 排在 `file10` 前面；中文、emoji、大小写都能正确排序 |
| 修改时间 新 → 旧 / 旧 → 新 | 按文件的实际修改时间 |
| 类型 A → Z / Z → A | 按扩展名分组 |
| 大小 大 → 小 / 小 → 大 | 按字节值，文件夹大小显示为 `—`（不会递归扫描整个目录） |

**文件夹始终排在文件前面**，升序降序都一样。排序在服务器端、分页之前完成，
所以翻页时顺序不会跳动。你选择的排序方式和列表/网格视图会**按设备记住**，下次打开还是它。

### 搜索与筛选

- **搜索**：顶部搜索框，默认只在**当前文件夹**里按名称匹配。
  在「筛选」里把搜索范围改成「整个共享」或「含子文件夹」后，会进行跨文件夹搜索。
- **筛选**（工具条上的「筛选」按钮）：
  - **类型**：文件夹、图片、视频、音频、文档、压缩包、其它
  - **搜索范围**：当前文件夹 / 含子文件夹 / 整个共享
  - **修改日期**：从 / 到（按本地日期，含当天）
  - **大小**：小于 1 MiB、1–100 MiB、100 MiB–1 GiB、大于 1 GiB
- 多个条件可以叠加。搜索和筛选**都受共享权限约束**，永远不会返回未授权共享里的内容。
- 如果结果数量达到服务器上限，列表上方会明确提示「结果已被截断」，不会假装完整。

### 最近 / 收藏

- **最近**：显示最近修改过的**文件**（默认 30 天内，可在配置中调整）。它不记录你的浏览历史，
  只按文件自身的修改时间排序，并且严格受设备权限限制。
- **收藏**：在 `…` 菜单里可以收藏文件或文件夹，**按设备保存**（换一台手机会是空的）。
  如果收藏的目标被删除、共享被关闭、磁盘离线或权限被收回，会显示为**失效**状态而不是假装还能打开。

### 列表 / 网格与缩略图

- **列表**适合管理（名称、时间、类型、大小一目了然）。
- **网格**适合看图片、视频和文件夹。
- 图片会按需生成小缩略图；生成失败或格式不支持时自动退回普通图标，不会显示破图。
- 切换视图**不会**改变当前的排序和筛选。

### 多选与批量操作

- **长按**任意条目进入多选（电脑上右键，或从 `…` 菜单选「选择」），之后点击条目即可勾选/取消。
- 底部会出现操作栏，显示已选数量，并提供：
  - **下载 ZIP**：先显示将要打包的文件数量和总大小，以及**哪些项目无法包含（逐项给出原因）**，
    确认后由浏览器直接下载。归档由服务器流式生成，不会把内容一次性读进内存。
  - **删除**：把选中的项目批量移入 LanDisk 回收站。
- 批量删除会**逐项返回结果**：成功的进入回收站，失败的会列出具体原因。
  本轮**没有**批量永久删除。

### 查看与预览

- 图片（PNG/JPEG/GIF/WebP/BMP/HEIC 等）、纯文本、PDF 支持内联预览；
- HTML、SVG、脚本等**主动内容只提供下载**，不会在本应用页面里执行；
- 文本预览由服务端以 JSON 返回，前端按纯文本显示，文件内容不会被当作网页渲染。

### 播放

- 音频、视频使用浏览器原生播放器（`<audio>` / `<video playsinline>`），支持暂停、拖动进度和原生全屏；
- 服务端完整支持 HTTP Range，可以边下边播、拖动到任意位置续播；
- **不做服务器转码。** 能否播放取决于 iPhone 对容器与编码的支持。
  基线建议：MP4（H.264 + AAC）。
  不支持的编码会在播放器上报错，并提示你下载后用其他播放器打开——这不代表文件损坏。

### 下载

点「下载」后由浏览器负责保存。页面会显示「已交给浏览器下载」。

> LanDisk **无法得知** iPhone 是否已经把文件存进了「文件」App。
> 服务端只记录「已经开始发送字节」，不会把它说成「手机保存成功」。
> 同样，服务器支持断点续传，但 Safari 的下载是否能由网页控制暂停/恢复并不由本应用决定。

### 上传

- 点「上传」选择一个或多个文件，队列会显示每个文件的进度；
- **如果目标目录已有同名文件，会先弹窗让你选择**：另存为副本（推荐）、跳过同名文件、
  或把已有文件移入回收站后上传。**绝不会静默覆盖**；
- 支持大文件分块上传，**严格按顺序写入**，单块默认最大 4 MiB；
- 中断或刷新页面后，可以在文件页下方看到未完成的会话，点「重新选择文件继续上传」，
  重新选中同一个文件即可从断点继续；
- 续传时会校验你重新选择的文件是否与原会话内容一致。同名同大小但内容不同的文件会被拒绝续传，
  避免拼装出损坏的文件；
- 只有服务端完成字节数校验、完整落盘并提交后，文件才出现在目录列表里。
  未完成的上传不会以正式文件的形式出现，也不能被下载或播放。

### 重命名

- 支持文件和文件夹改名，支持中文、空格、emoji；重命名对话框默认只选中主文件名（不含扩展名）；
- 支持**仅大小写变化**的改名（内部用临时名称安全完成，失败会回滚）；
- 目标已存在同名文件时**拒绝**，不会覆盖；
- 不接受包含路径分隔符、绝对路径、Windows 保留设备名（CON、NUL、COM1…）、
  以空格或句点结尾的名称。

### 删除与恢复

- 删除前会要求确认；
- 「删除」是把对象移入 **LanDisk 自己的回收站**，不是 Windows 系统回收站；
- 「回收站」标签里可以恢复；如果原位置已经被占用，会要求你输入一个新的名称另存恢复；
- 手机只能看到并恢复自己有删除权限的那些共享里的对象；
- **永久清空只能在电脑端管理页操作，并且需要再次确认。**

> 应用内回收站**不等于备份**，也不能保证磁盘损坏后还能恢复。重要数据请另做备份。

## 8. 移动硬盘（可移动磁盘）

- 移动硬盘必须已经被 Windows 挂载，并且当前运行 LanDisk 的用户有访问权限；
  LanDisk 不会自动解锁 BitLocker、不会格式化、不会修改磁盘权限。
- LanDisk 用 **卷 GUID**（`\\?\Volume{…}\`）识别磁盘，而不是 `E:` 这样的盘符。
  换盘符不会让它认错盘，但会要求你在管理页「重新确认磁盘」。
- 拔出移动硬盘后：
  - 手机上该共享会显示为「离线」，所有浏览/下载/播放/上传/改名/删除都会明确失败；
  - 排队的上传会报失败，**不会**假报成功；
  - 不会有任何操作被缓存下来等磁盘回来偷偷执行。
- 重新插好（盘符可能变了）后，点一次「重新确认磁盘」即可恢复。
- 如果另一块盘占用了原来的盘符，LanDisk 会因卷身份不符而拒绝服务，**不会**把操作写到新盘上。
- 如果磁盘被重新格式化，卷身份会变化，必须在管理页重新确认才能继续使用。

## 9. 卸载 / 升级 / 数据保留

### 卸载

1. 在管理页退出 LanDisk（或直接关闭程序窗口）。
2. 删除解压出来的程序目录即可，LanDisk 没有安装任何系统服务、计划任务或开机启动项。
3. 数据保留在 `%LOCALAPPDATA%\LanDisk`，包含配置、共享与设备记录、回收站索引和日志。
   如果确认不再需要，可以手动删除整个目录。
   删除前建议先到「回收站」里把还需要的内容恢复出来。
4. 共享目录里的文件**永远不会**被卸载过程删除。
5. iPhone 上如果安装过证书描述文件，记得按第 5 节的方法删除。

### 升级

用新版本替换程序目录即可。`%LOCALAPPDATA%\LanDisk` 中的配置、共享、设备配对、回收站索引都会被保留。
如果新版本提示卷身份需要重新确认，到「共享」里点一次「重新确认磁盘」。

> 说明：因为 `%LOCALAPPDATA%` 位于系统盘，**跨卷的删除**（共享目录与数据目录不在同一卷时）
> 会走「先完整复制并校验、再删除原文件」的带日志流程。同卷删除则是原子改名，更快也更安全。

## 10. 数据放在哪里

| 内容 | 位置 |
|---|---|
| 配置、共享、设备、回收站索引、日志 | `%LOCALAPPDATA%\LanDisk` |
| TLS 证书与私钥 | `%LOCALAPPDATA%\LanDisk\tls`、`%LOCALAPPDATA%\LanDisk\secrets` |
| 上传暂存与回收站内容（同卷） | 共享所在卷根目录下的 `.landisk-data\` |
| 上传暂存与回收站内容（卷根不可写时） | `%LOCALAPPDATA%\LanDisk\store\<卷哈希>\` |

`.landisk-data` 是 LanDisk 的内部目录：它**不会**出现在任何目录列表中，
也**无法**通过任何文件接口访问或下载，即使你共享了整个卷。
如果你共享了整个卷并希望彻底清理，可以在停止 LanDisk 后手动删除该目录（会丢失回收站内容）。

## 11. 故障排查

管理页「自检」标签会给出针对当前状态的具体提示。常见问题：

| 现象 | 可能原因与处理 |
|---|---|
| 手机打不开页面，电脑上本机打开正常 | 局域网访问未开启；或未重启程序；或防火墙未放行（见 4.3）；或网络类型是「公用」；或路由器开了 AP 隔离 |
| 手机提示「无法连接到服务器」 | 电脑 IP 变了（重启路由后 DHCP 重新分配）；用管理页「网络」里显示的当前地址 |
| 电脑睡眠后手机连不上 | Windows 进入了睡眠/休眠。到「电源和睡眠」里把睡眠设为「从不」，或改用「高性能」电源计划 |
| 启动时提示端口被占用 | 换一个端口（管理页「网络」）；或用 `netstat -ano \| findstr :8891` 找到占用进程 |
| Safari 提示「此连接非私人连接」 | 证书未安装或未在「证书信任设置」中打开完全信任（见第 5 节）；或证书 SAN 里没有你正在使用的地址，需要重新生成证书 |
| 视频一直转圈或提示不支持 | 容器/编码不被 iPhone 支持。本版本不做转码，请下载后用其他播放器打开；基线请用 MP4（H.264 + AAC） |
| 上传失败提示「暂存空间不足」 | 目标卷可用空间不足，或在「网络」设置里配置的暂存上限太小 |
| 上传停在某个进度不动 | 手机切后台/锁屏会暂停传输。回到页面刷新后可在「传输」里继续 |
| 共享显示「离线」 | 移动硬盘已拔出或盘符变化（见第 8 节） |
| 共享显示「身份不匹配」 | 磁盘被重新格式化，或另一块盘占用了旧盘符。到「共享」点「重新确认磁盘」 |
| 手机上看到空列表 | 电脑端还没有添加共享，这是首次启动的正常状态 |
| 忘记管理令牌 | 打开 `%LOCALAPPDATA%\LanDisk\admin-url.txt` 复制完整网址；或删除 `secrets\admin-token.txt` 后重启程序生成新的 |

## 12. 最短实机验证清单

如果你要自己确认这套东西在真机上确实可用，按下面的最小步骤走一遍（预计 10 分钟）：

1. 新建一个空文件夹 `D:\LanDiskTest`，放入一张图片、一段 MP4（H.264/AAC）和一份文本文件。
2. 电脑端添加共享 `D:\LanDiskTest`，勾选全部三项写权限。
3. 生成配对请求并配对手机，把设备权限改为「可读写」。
4. iPhone 打开页面：查看图片、拖动播放视频、下载文本文件。
5. 上传一个测试文件、把它改名、删除、再从回收站恢复，核对恢复后的内容一致。
6. 切换到后台再切回来、刷新页面，确认状态显示正确。
7. 若使用移动硬盘：用移动硬盘上的目录重复第 4–5 步，然后正常弹出硬盘，确认手机端显示离线且操作失败；
   重新插回后点「重新确认磁盘」，确认恢复可用。

## 12. Windows 桌面应用（`LanDisk.exe`）

### 12.1 启动与退出

- **双击 `LanDisk.exe`** 即可。程序没有控制台窗口，启动后会出现一个小窗口和一个通知区域（托盘）图标。
- 关闭窗口**不会**停止服务：窗口会隐藏到托盘，手机依然可以访问。第一次这样做时窗口里会说明这一点。
- 真正退出：右键托盘图标 →「退出」，或窗口里的「退出 LanDisk」。退出前会确认一次，因为退出后手机将无法访问。
- 再次双击 `LanDisk.exe`（或再运行一次）**不会**启动第二个实例，只会把已经打开的窗口调到前面。

### 12.2 窗口里能做什么

| 按钮 | 作用 |
|---|---|
| 打开管理页面 | 用系统默认浏览器打开 `http://127.0.0.1:8891/admin`（本机访问会自动进入，无需令牌） |
| 手机连接二维码 | 打开管理页的「添加设备」，直接显示可供手机扫描的二维码 |
| 重启服务 | 停止并重新启动后台服务（不需要退出程序）。**不会**修改端口、共享或设备 |
| 打开数据目录 | 用资源管理器打开 `%LOCALAPPDATA%\LanDisk` |
| 退出 LanDisk | 停止服务并退出程序 |

窗口里也会显示本机管理地址、局域网监听地址与一小块运行记录。

### 12.3 开机自动启动

窗口底部有「开机自动启动」复选框，**默认不勾选**。

- 勾选后只会在 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 写入一项
  `LanDisk`，值为 `"<安装路径>\LanDisk.exe" --startup`；这是当前用户级的设置，不需要管理员权限，
  取消勾选即可完全移除。
- 以这种方式启动时，LanDisk **直接进入托盘**，不会弹出窗口打断你。
- LanDisk **不会**自动开启这个选项，也不会创建计划任务、系统服务或修改全局设置。

### 12.4 日志在哪里

桌面外壳没有控制台，所以服务端日志写入：

```
%LOCALAPPDATA%\LanDisk\logs\landisk.log
```

超过 8 MiB 会轮转为 `landisk.log.1`。窗口内的「运行记录」只保留最近若干条界面提示。
如果程序在启动阶段崩溃，会额外写入 `%LOCALAPPDATA%\LanDisk\shell-crash.log`。

### 12.5 端口被占用怎么办

LanDisk 固定使用 **8891（HTTP）** 与 **8892（HTTPS）**。如果启动时提示端口被占用：

1. 先确认是不是已经有一个 LanDisk 在运行（托盘图标）；
2. 用 `netstat -ano | findstr :8891` 找到占用进程；
3. 或者用命令行临时换端口：`LanDisk.exe --port 18991 --https-port 18992`。

**LanDisk 不会自动改端口**——自动改端口会让手机上已经保存的地址失效，因此这必须由你决定。
在管理页「网络」里修改端口后需要重启服务才会生效。

## 13. 系统更新

### 13.1 更新包是什么

更新包是管理员提供的一个 `.lupd` 文件（例如 `LanDisk-update-1.2.0.lupd`）。
它由 LanDisk 的**发布签名私钥**签名；程序内置对应的公钥，只接受由这个私钥签名的包。

> **重要**：如果不是从可信的管理员那里拿到的 `.lupd`，不要上传。
> 尽管签名会拦住绝大多数篡改，但拿到发布私钥的人可以发布任何内容。

### 13.2 升级步骤

1. 打开管理页（托盘菜单「打开管理页面」）。
2. 切到「系统更新」标签。
3. 点「选择文件」，选取 `.lupd` 包并等待上传完成（页面会显示上传进度）。
4. 上传完成后页面会显示：目标版本、签名者标识、包 SHA256、文件数量与总大小、
   将写入与删除的文件数、以及更新说明。**此时还没有安装任何东西。**
5. 确认无误后点「安装并重启」，在弹出的确认框里再确认一次。
6. 页面会提示"正在安装并重启"。LanDisk 会：备份当前程序与状态 → 停止服务 → 替换文件 →
   重新启动 → 自检。**请不要关闭这个页面**，它会在服务恢复后自动刷新。
7. 成功：页面显示新版本，更新记录里出现一条「完成」。
   失败：程序**自动回滚**到原来的版本并重新启动，页面用红色横幅说明失败原因。

### 13.3 升级不会改变什么

- **固定的 8891 / 8892 端口不变**；
- **共享目录配置、已配对的手机会员、收藏、最近的偏好设置不变**；
- **手机不需要重新配对**，升级后原来的手机会话继续有效；
- **共享目录里的任何文件都不会被读取、移动或删除**——更新只写程序自己的目录；
- **你自己放进 LanDisk 安装目录的文件不会被删除**：程序只会删除它自己安装过的文件。

### 13.4 如果升级失败了

自检不通过的更新会自动回滚，并把原因写进管理页「系统更新」里。这时你可以：

1. 在页面里查看失败原因（例如"更新后自检未通过"）；
2. 查看更新日志：`%LOCALAPPDATA%\LanDisk\updates\updater.log`；
3. 检查 `%LOCALAPPDATA%\LanDisk\updates\state.json` 里的 `lastOutcome` 与 `lastMessage`；
4. 备份保留在 `%LOCALAPPDATA%\LanDisk\updates\backup\<时间戳>-<版本>\`，
   里面同时有当时的程序文件与状态文件副本（默认保留最近 3 份）。

如果连程序都启动不起来：解压一份完整的 `LanDisk-win-x64.zip` 覆盖安装目录即可；
**你的共享配置与配对设备在 `%LOCALAPPDATA%\LanDisk` 里，不会被覆盖包影响。**

### 13.5 怎么判断更新包是真的

- 页面显示的**签名者标识**应当是 `ac3ff1673b23518a`（内置发布公钥的指纹）；
- 「自检」标签里的 `release-key` 一项应当是 `ok`；
- 上传被拒绝时会给出明确的机器码，例如 `SIGNATURE_INVALID`（签名不对）、
  `HASH_MISMATCH`（内容与签名清单不符）、`VERSION_NOT_NEWER`（版本不比当前新）、
  `ARCHITECTURE_MISMATCH`（不是给这台电脑的包）。

只要出现其中任何一个，就说明这个包**没有被安装**，程序状态没有任何改变。
